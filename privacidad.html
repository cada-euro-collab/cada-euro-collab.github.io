Política de privacidad

Que no se te escape ni uno.

Tu información financiera es tuya. Cada Euro está diseñada para registrar ingresos, gastos, pagos fijos, presupuestos y objetivos de ahorro sin tener que crear una cuenta ni conectar un banco.

1. Quién ofrece la aplicación y contacto

Aplicación: Cada Euro.
Editor: Cada Euro (proyecto independiente).
Correo de privacidad y soporte: cadaeuro.soporte@gmail.com.

Para consultas sobre esta política o sobre el funcionamiento de la aplicación, puedes contactar a través de ese correo.

2. Qué información utiliza Cada Euro

La aplicación permite introducir voluntariamente ingresos, gastos, importes, conceptos, categorías, fechas, pagos periódicos, presupuestos, objetivos de ahorro y un nombre o apodo opcional.

Estos datos se guardan en el almacenamiento local del dispositivo, mediante las funciones de almacenamiento del navegador que utiliza la aplicación. No se crea una cuenta en un servidor de Cada Euro ni se sincronizan automáticamente los registros financieros con nosotros.

3. Para qué se usan los datos

La aplicación procesa los registros en el propio dispositivo para mostrar saldos, dinero disponible, estadísticas, gastos pendientes, presupuestos y progreso de objetivos de ahorro.

Actualmente, Cada Euro no solicita credenciales bancarias, no integra publicidad y no utiliza herramientas propias de analítica o seguimiento. No vendemos ni compartimos los movimientos financieros introducidos por el usuario.

4. Copias de seguridad y restauración

La opción «Exportar copia» genera un archivo JSON con los datos introducidos. El usuario decide dónde guardarlo o con quién compartirlo. Cada Euro no envía automáticamente ese archivo al desarrollador.

La opción «Restaurar copia» permite seleccionar un archivo desde el dispositivo para sustituir los datos locales existentes. Si guardas copias en servicios externos, el tratamiento de esos archivos dependerá de dicho servicio y de tu configuración.

5. Alojamiento web y datos técnicos

La versión web de Cada Euro se distribuye mediante GitHub Pages. Para entregar las páginas y los archivos necesarios, el proveedor de alojamiento puede tratar datos técnicos como la dirección IP, el navegador, el dispositivo y la fecha de acceso, de acuerdo con su propia política de privacidad.

Los servicios de Android y Google Play también pueden tratar información técnica relacionada con la instalación y el funcionamiento conforme a sus políticas aplicables. Estos procesos no implican que Cada Euro envíe tus movimientos financieros al desarrollador.

6. Conservación y eliminación

Los datos introducidos permanecen guardados en el dispositivo hasta que el usuario los borra, elimina los datos de almacenamiento asociados o realiza una acción que los sustituye. La aplicación incluye en Ajustes → Borrar todos los datos de este dispositivo una opción para eliminar los registros locales.

Desinstalar la aplicación o borrar los datos del navegador puede causar la pérdida de los registros. Se recomienda guardar una copia antes de hacerlo. Las copias exportadas solo pueden eliminarse desde los lugares donde el usuario las haya guardado.

7. Seguridad

La página se distribuye mediante HTTPS. Los registros se almacenan localmente y no se transmiten a un servidor de Cada Euro. No obstante, el almacenamiento local y los archivos JSON exportados no están cifrados por Cada Euro. Por ello, recomendamos proteger el teléfono con bloqueo de pantalla y mantener las copias de seguridad en ubicaciones privadas.

8. Comunicación por correo

Si decides escribirnos, recibiremos la dirección de correo y la información que incluyas voluntariamente en tu mensaje para atender la consulta. Conservaremos la correspondencia durante el tiempo razonablemente necesario para resolverla y cumplir posibles obligaciones legales. Puedes solicitar información o la eliminación de tus mensajes escribiendo a cadaeuro.soporte@gmail.com, cuando proceda legalmente.

9. Menores de edad

Cada Euro es una herramienta general de organización financiera. No está diseñada específicamente para niños ni solicita deliberadamente datos personales de menores.

10. Cambios de la política

Si añadimos funciones que cambien cómo se utilizan o comparten los datos —por ejemplo, sincronización en línea, anuncios o herramientas de analítica— actualizaremos esta política antes de ponerlas en funcionamiento y proporcionaremos los avisos que correspondan.
